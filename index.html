01 · 一加 AI 中台（模型接入与网关）
github.com/yzxz111/yijia-ai-platform ↗
个人项目 · Java / Infra

面向大模型调用构建的 API 管理与模型网关底座，打通模型接入、流式协议治理、并发限流及控制台，为上层应用提供统一接口。

Java Spring Boot WebFlux PostgreSQL Redis Lua OpenAPI 3.1 Node.js Vue 3
  • 模型接入与同源安全 实现 OpenAPI 3.1 接口契约与 Node.js 客户端，串联登录、Bootstrap 托管 API Key、模型目录、额度查询与 SSE 对话，校验返回地址防凭证重定向。
  • SSE 治理与防重复计费 处理 UTF-8 跨块、15s : keep-alive 心跳、usage 及流中 failureFrame；通过 FirstChunkGate 划分首帧前后边界，仅对准入 429 有限退避。
  • Redis Lua 租约 TTL 修复 修复 RedisRequestLimitStore 中短租约覆盖缩短共享并发 ZSET TTL 的缺陷；补齐 Retry-After、结构化错误码与 X-Request-ID。
  • 三段式结算与回归验证 执行 Reserve → Settle → Release 额度预留结算，完成控制台联调；基于本地模拟上游通过 294 项网关回归与 25 项客户端协议测试。

02 · LogOps-Agent 智能排障平台
github.com/yzxz111/logops-agent ↗
个人项目 · Python / Agent

面向微服务异常排查研发的智能排障 Agent 后端系统，对接模型网关输出带来源引用的诊断报告，支持 OpenAI 兼容。

Python FastAPI (SSE) LangGraph Qdrant BM25 FastMCP Pydantic pytest
  • LangGraph 状态机与 HITL 构建异常提取、多路取证、相关性评估、二次检索与 interrupt() / Command(resume) 人工确认恢复流程；配置步数与 Token 预算熔断。
  • 章节分块与 RRF 混合检索 25 篇手册按章节切分为 125 块（保留行号溯源），结合 BM25 + Qdrant RRF（k=60）、Query 改写与按 doc_id 多样性重排。
  • 只读 MCP 与上下文治理 基于 FastMCP 封装只读日志/源码工具，落地 resolve() 防路径穿越校验、8 类正则脱敏及报错窗口压缩。
  • 离线评测与质量边界 30 条离线评测集 Recall@3 达 100%、MRR 达 0.9833，17 项 pytest 全通过；并主动识别基础集 BM25 偏高问题，设计无错误码口语样本持续补强。

03 · 一加灵犀 AI 桌面工作台
github.com/yzxz111/yijia-lingxi ↗
个人项目 · Electron / React

基于一加 AI 中台打造的桌面工作台，按 OpenAI 兼容契约接入模型目录、实时额度与流式对话，管理上下文与本地数据。

Electron React Vite JavaScript SSE AbortController DOMPurify Playwright
  • 多轮交互与流式取消 实现多轮流式对话、6 类助手、历史搜索、收藏、文本附件（二进制 \0 检测）与 Markdown 导出；经 AbortController 立即中止实际网关流。
  • 流式解码与上下文净化 基于 TextDecoder('utf-8', {fatal:true}) 增量解码防跨块乱码，过滤未完成/失败消息不入下轮上下文，生成请求绝不自动重试。
  • 桌面沙箱与内存态密钥 启用上下文隔离、沙箱并禁用渲染进程 Node.js；受限 preload / IPC 代理网络并校验 senderFrame，API Key 仅驻留内存不落盘，DOMPurify 禁 img/iframe。
  • 打包与受控环境验收 完成 Windows x64 免安装绿色版打包；在本地受控 HTTP 服务下通过 13 项协议与 15 项桌面端交互测试。
