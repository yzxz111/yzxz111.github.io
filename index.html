LogOps-Agent 智能排障平台
github.com/yzxz111/logops-agent ↗
个人独立开发 · Python / Agent

面向微服务与网关异常排查场景，构建融合 LangGraph 状态机、Agentic RAG 与只读 MCP 工具的自动诊断平台，直连自研模型网关实现流式推理与链路追踪。

Python 3.11 FastAPI (SSE) LangGraph Qdrant BM25 FastMCP Pydantic pytest
  • 状态机编排 基于 LangGraph 设计异常提取、多路取证、相关性评估与二次检索循环流程；内置最大步数/Token 预算熔断与高危操作人工确认（中断恢复）。
  • Agentic RAG 对 25 篇故障手册按章节分块（125 块），结合 BM25 与 Qdrant RRF 混合检索、Query 改写与多样性重排，并强制输出 Citation 引用溯源。
  • 工具与上下文 基于 FastMCP 封装只读日志切片与源码定位工具（防路径穿越与 Pydantic 校验）；实现堆栈脱敏、错误窗口提取及 Tool Result 摘要压缩。
  • 离线评测与单测 构建 30 条离线故障评测集，Agentic 模式 Recall@3 达 100.00%、MRR 0.9833，工具与根因命中率 100%，17 项 pytest 全部通过。
